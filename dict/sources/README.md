# Edits

Vowel quantities were updated to modern standards and editing was performed to allow entries to be parsed programmatically (e.g. `-īvī (-iī)` was rewritten to `-īvī | -iī`, extraneous information was removed from the entry heads, etc).

Each file has a slightly different format and the script `process_dicts.py` was written to process and harmonize entries across files for comparison. It is provided here for historical purposes and in case any new files need to converted; any updates required in the `dict.txt` file should be manually applied to the sources here if needed.

## Sources 

Each `txt` corresponds to the cleaned and OCRed source from each reader, mapped as follows:

 - `dict_app_fab.txt`: `F`
 - `dict_app_pons.txt`: `PT`
 - `dict_dale.txt`: `RCR`
 - `dict_paine_sec.txt`: `SA`
 - `dict_strange_ovid.txt`: `ONE`
